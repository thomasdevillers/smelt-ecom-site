# Historical records

These documents preserve past designs, migration evidence and operator decisions. They can contain superseded instructions and references to private local evidence.

Start with [migration status](../migration-status.md) for outstanding work, [architecture](../architecture.md) for the current code map, and [operations](../operations.md) for routine procedures.

- `migration/`: dated migration plans, cutover results and recovery notes.
- `emails/`: original transactional-email design and implementation plan.

Applied database migrations live in `drizzle/` and remain authoritative migration history. Private data/backups belong outside this archive.
